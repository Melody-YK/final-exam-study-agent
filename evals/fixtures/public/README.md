# Public Evaluation Seed

`rag-seed-v1.jsonl` is self-authored for this repository and dedicated under
`CC0-1.0`. It contains synthetic operating-system facts, retrieval rankings,
evidence identifiers, and an unanswerable query. It contains no private course
material and no reference-answer text.

The authoritative hash, attribution, role, and license metadata live in
`evals/manifests/public.json`.
